# Nexus Trading AI

Cloud-ready single-service trading dashboard.

Current mode: PAPER TRADING.
Real-money execution is intentionally disabled.

Features:
- Live crypto reference price from CoinGecko when available
- Deterministic fallback data
- BUY/SELL/HOLD gate
- Confluence-style score
- Paper position management
- Kill switch
- Health endpoint
- Responsive mobile dashboard
- Same-origin API and UI
